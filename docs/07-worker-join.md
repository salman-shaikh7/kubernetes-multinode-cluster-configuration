# Worker join

Generate a fresh join command on the control plane:

```bash
sudo kubeadm token create --print-join-command
```

Run the generated command with `sudo` on both `k8s-worker-1` and `k8s-worker-2`. It will have this shape:

```bash
sudo kubeadm join 192.168.122.131:6443 \
  --token <bootstrap-token> \
  --discovery-token-ca-cert-hash sha256:<ca-certificate-hash>
```

The token and hash placeholders must be replaced by the values generated by kubeadm. From the control plane, verify both workers:

```bash
kubectl get nodes -o wide
```

Expected addresses:

```text
k8s-control-plane   192.168.122.131
k8s-worker-1        192.168.122.94
k8s-worker-2        192.168.122.38
```

All three nodes should report `Ready`. If a worker needs to be rejoined after a failed attempt, run `sudo kubeadm reset` on that worker, prepare the node again, and use a newly generated join command.
